# Recruiter candidate review

Date: 2026-11-16

## Intent and acceptance

Implement the user's revised employer candidate-detail workflow, superseding the E01 revision-5 runtime presentation without rewriting its saved experiment records. Preserve the process history and candidate-view boundaries. Compose one RecordSheet with About candidate (independent submitted answer, CV open/download/disclosure), Assessment (five categories), recruiter note and Save. Saving an uncertain assessment offers a named Base UI modal with Yes/No; only Yes reveals additional project material. Decline/Escape preserves the saved review and allows reopening the offer. A second form retains the previous note. Both assessment rounds survive reload/export/import. Definite invite/reject decisions advance local process stages; all uncertain categories stay reviewed. Explain the next stage before Save and confirm it afterward. Never send real invitations.

Use local role/function-specific question guidance and snapshot it with new submissions. Add an optional candidate AI-use answer; missing historical answers stay explicit, never fabricated. Keep legacy project schemas and E01 data readable. Use synthetic data only. Test local operations, invalid import/recovery, snapshots, modal keyboard/focus, all outcomes and desktop/mobile/320px. Run scripts/verify and separate review.

## Design composition

Reuse Poster People C01 actions, C02/C04 labelled controls, C18 modal and C22 reading sections through host Base UI primitives, RecordSheet, CvAttachment and ProcessTimeline. Paper canvas, white outlined r24 surface, 26px Geist Serif section headings and pink primary action. Source: GUI.md, design-system README/IMPLEMENTATION/VERIFICATION, agent-kit design/API and human component reference. No immutable-kit change. Section navigation uses native in-page focus buttons, not tabs or a simulated stepper. Show a closed CV preview initially to keep assessment easy to reach. Later-stage recruiting actions remain available separately from screening assessments.
