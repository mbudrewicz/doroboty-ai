Date: 2026-11-18

## Intent and acceptance

Implement the user's attached process diagram and three explicit clarifications: open the information choice after Next/Save, map declined-information lean choices to invitation/rejection, and show five information areas retaining AI by combining project context and actual use. The second assessment must start empty and omit the previous assessment from the rendered UI, including on reload. Save the first assessment independently. Only Unknown remains reviewed when finishing either branch. Yes records exposure; No completes without exposure; closing the dialog only suspends the pending choice. Preserve process history, CV actions, role boundaries, saved notes and existing research records. New completed flows end after one second assessment and permit an optional recruiter note without changing the decision. Never reinterpret older completed reviews or rewrite submitted answers.

Use the existing Poster People RecordSheet, Base UI Dialog/Button/Textarea, native radios and focusable section headings. Reuse current local kit typography, contours, spacing and responsive composition; no kit changes. Group the existing six source fields into five recruiter reading blocks without rewriting candidate submissions or changing the candidate authoring flow. Record current behavior in FEATURES.md and the moderator scenario. Run scripts/verify, appropriate unit/browser checks and a separate review.
